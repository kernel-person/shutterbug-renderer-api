# Jobs and progress

`submit` performs bounded admission and returns a `RenderTask`; queue admission can fail synchronously with `QUEUE_FULL`. `RenderSettings.timeout()` begins at task creation and covers queueing, preparation, native work, diagnostics, and output copy. Poll `progress()` without blocking: phases are `QUEUED`, `PREPARING`, `DECODING`, `RENDERING`, `POST_PROCESSING`, `DIAGNOSTICS`, `COPYING_OUTPUT`, and terminal `COMPLETE`. Progress is monotonic; successful completion is `COMPLETE/10_000`. `cancel()` returns true only when it wins a nonterminal transition; completion then fails with `CANCELLED`, while a terminal race returns false. `status()` is the coarse task state. See the [complete sample plugin](https://github.com/kernel-person/shutterbug-renderer-api/tree/v1.0.0/sample-plugin).
