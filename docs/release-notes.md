# Release notes

## SDK v1.0.1

The free SDK distribution moves to JitPack tag `v1.0.1`. Its public packages, signatures, and v1 binary baseline are unchanged. This release adds the sales-ready operator and developer guides, Maven and Gradle consumer builds, full public-type Javadoc routing, compile-owned practical examples, compatibility and Windows-pending language, recovery guidance, and deterministic documentation/export verification.

## Renderer 1.0.0

The commercial product remains Renderer 1.0.0. macOS ARM64 and Linux x86-64 are supported for the exact documented adapter. Windows x86-64 is an intended launch target but remains pending and not yet supported until exact Windows canary and Paper acceptance evidence is recorded.
