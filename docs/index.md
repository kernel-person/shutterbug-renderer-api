# ShutterBug Renderer

ShutterBug Renderer 1.0.0 by Kernel Person is a separately installed rendering provider for Java 21 plugins on the exact documented Paper adapter. The published free Apache-2.0 SDK at `com.github.kernel-person:shutterbug-renderer-api:v1.0.2` contains consumer contracts and converters; it does not contain, unlock, or redistribute the commercial renderer. Its immutable tag and JitPack artifact are verified through fresh Maven and Gradle consumers. The published `v1.0.1` remains available unchanged.

Server owners should begin with [installation and activation](operator-guide.md). Plugin developers should use [Maven or Gradle setup](setup.md), then follow the [complete sample walkthrough](sample-walkthrough.md) and [public API reference](api-reference.md). Read the [compatibility matrix](compatibility.md) before deployment: Windows x86-64 is an intended target but remains pending and not yet supported.

## Build free or paid add-ons

Both are welcome. You may sell your own plugins that depend on ShutterBug Renderer. Tell buyers that ShutterBug Renderer is required and purchased separately: the server owner needs a valid provider license within its seat limits, not every player or a separate purchase per add-on on the same server. Do not redistribute the commercial provider, its native binaries or activation credentials.

The [four independent Java examples](https://github.com/kernel-person/shutterbug-renderer-examples/releases/tag/v1.2.0) are Apache-2.0 source you can adapt: Postcards, Redstone Camera, Painter's Easel and Admin POV Monitor. Begin with Postcards, then follow the [example walkthrough](sample-walkthrough.md). Published Examples 1.2.0 use the verified SDK v1.0.2, shared POV/map capture and six-direction cameras; they retain the byte-identical resource pack 1.1.0. Their publication does not establish matching-provider Paper acceptance or genuine buyer activation. Latest exact-artifact client acceptance remains separately documented in the examples repository.
