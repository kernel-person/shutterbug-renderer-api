# Troubleshooting

If the service is absent, retain optional plugin behavior and retry discovery after the provider is available. If a client becomes inactive, close consumer state, rediscover the service, recapture opaque scenes, and resubmit. Check capabilities before selecting profiles or attachments. See the [complete sample plugin](https://github.com/kernel-person/shutterbug-renderer-api/tree/v1.0.0/sample-plugin).
